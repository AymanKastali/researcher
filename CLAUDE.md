# researcher

## Agent skills

### Issue tracker

Issues live as GitHub issues in `AymanKastali/researcher`, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, used verbatim as label strings. See `docs/agents/triage-labels.md`.

### Teaching standard

Every topic is a `mattpocock-skills:teach` workspace. Rules, quiz requirements and the checker. See `docs/agents/teaching-standard.md`.

### Topic independence

A topic never refers to another topic. Teach the concept in place instead. See `docs/agents/topic-independence.md`.

### Design system

One shared `assets/` at the repo root styles every page. Never add a second copy. See `docs/agents/design-system.md`.

### Domain docs

Single-context — `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
