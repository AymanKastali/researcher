Glossary

The vocabulary of the mattpocock-skills plugin at 1.2.3 — the set's own words where it has one, and this workspace's where it does not.

Canonical source: GLOSSARY.md in this topic. The two are kept in step; this page is the readable rendering.

Invocation

Skill

A directory holding a SKILL.md whose frontmatter names it and whose body is the instruction an agent follows. The unit the plugin ships.

Avoid: command, prompt, macro.
Promoted skill

A skill in the engineering/ or productivity/ bucket, and therefore listed in plugin.json and shipped by the plugin. There are twenty-five.

Avoid: installed skill, available skill.
User-invoked skill

A skill carrying disable-model-invocation: true, reachable only by a human typing its name. No other skill can reach it. Fourteen of the twenty-five.

.agents/invocation.md:5. Avoid: manual skill, slash command.
Model-invoked skill

A skill with no such flag, reachable by the agent on its own as well as by the human. Eleven of the twenty-five.

.agents/invocation.md:6. Avoid: automatic skill, auto-skill.
Context pointer

The description: string in a model-invoked skill's frontmatter. It is permanently loaded and it is what the agent matches a request against, so it is the trigger rather than a summary.

writing-for-agents/SKILL.md:12. Avoid: summary, blurb, docstring.
Inoperative instruction

A line inside a skill telling the agent to run a user-invoked skill. The invocation invariant makes it unexecutable, so it can only be read as a message to the human. Six exist in 1.2.3.

This workspace's term; the set has none. Avoid: broken link, bug, dead reference.

Structure

Flow

A path through several skills. The set has one main flow and three on-ramps that merge onto it.

ask-matt/SKILL.md:11. Avoid: workflow, pipeline, process.
Main flow

grill-with-docs → to-spec → to-tickets → implement → code-review. The route most work travels, printed identically in four places in the tree.

Avoid: the chain, the happy path.
On-ramp

A starting situation that generates work and then merges onto the main flow: /triage, /diagnosing-bugs, /wayfinder.

Avoid: entry point, trigger.
Vocabulary layer

A model-invoked skill that runs beneath the others as the single source of truth for a set of words — /domain-modeling for the domain, /codebase-design for module shape. Consulted, not run as a session.

ask-matt/SKILL.md:56. Avoid: helper, library, utility skill.

The interview

Grilling

The interview primitive: relentless questioning in rounds until a shared understanding is reached. Five skills run it internally.

Avoid: interview, Q&A, discovery.
Design tree

The structure grilling maps a problem onto — every decision branching into the decisions that hang off it.

grilling/SKILL.md:6. Avoid: decision tree, outline.
Frontier

Every decision whose prerequisites are already settled — the questions askable now without guessing. The word carries a second, related sense in /to-tickets and /wayfinder: every ticket whose blockers are all done. Same idea, applied to questions in one case and work in the other.

grilling/SKILL.md:8; to-tickets/SKILL.md:66. Avoid: open questions, backlog, next up.
Facts/decisions split

Grilling's contract. Finding facts is the agent's job, always; making decisions is the human's, always. An agent that answers its own question has broken the skill rather than interpreted it liberally.

grilling/SKILL.md:20; wayfinder/SKILL.md:75. Avoid: division of labour, roles.
Shared understanding

The state that ends a grilling session, and it must be confirmed by the human before anything is acted on. The frontier being empty is the condition; the confirmation is the gate.

grilling/SKILL.md:22. Avoid: agreement, sign-off, alignment.

Building

Spec

The document /to-spec synthesises from a conversation without interviewing, and publishes to the tracker labelled ready-for-agent. It exists because context windows end.

Avoid: PRD, requirements, design doc.
Seam

The public boundary you test at: the interface where you observe behaviour without reaching inside. Agreed with the human before any test is written.

tdd/SKILL.md:20. Avoid: boundary, interface, test point.
Tracer-bullet ticket

A slice cutting a narrow but complete path through every layer, demoable on its own, sized to fit one fresh context window.

to-tickets/SKILL.md:31-34. Avoid: story, task, issue.
Blocking edge

A declared dependency from one ticket to another, native on a real tracker and plain text on a local one. What makes a frontier computable.

Avoid: dependency, link, blocker.
Wide refactor

One mechanical change whose blast radius fans across the codebase, so no vertical slice can land green. Sequenced expand–migrate–contract instead.

to-tickets/SKILL.md:40. Avoid: big refactor, sweeping change.
Fixed point

The commit, branch, tag or merge-base /code-review compares against, via git diff <fixed-point>...HEAD. Committed work only.

code-review/SKILL.md:21. Avoid: base, baseline, start point.

Mapping

Map

The wayfinder:map issue holding a destination and pointers to its decision tickets. An index, never a store — a decision lives in exactly one place.

wayfinder/SKILL.md:23. Avoid: plan, roadmap, epic.
Destination

What a map is finding its way to, settled first because it fixes the scope.

Avoid: goal, outcome, target.
Fog

The part of the work that cannot yet be stated as a question, held in the map's Not yet specified section. The test for graduating it is whether the question can be stated precisely now, not whether it can be answered.

wayfinder/SKILL.md:85-91. Avoid: unknowns, TBD, backlog.
Decision ticket

A child of the map that produces a decision rather than a deliverable. One of four types: research, prototype, grilling, task.

Avoid: spike, investigation, chore.
HITL / AFK

Whether a ticket resolves through live exchange with a human, or is driven by the agent alone.

wayfinder/SKILL.md:75. Avoid: manual/automatic, interactive/batch.

Sessions

Phase

A chunk of work inside a session — the grilling, the implementation, the QA. It ends when you think "ok, we're done with that".

PHASE-BOUNDARIES.md:3. Avoid: stage, step, sprint.
Phase boundary

The gap between two phases, and the only place the continue/clear/handoff/subagent/compact decision belongs.

PHASE-BOUNDARIES.md:5. Avoid: checkpoint, breakpoint.
Smart zone

The window — about 150k tokens — within which the model still reasons sharply. The budget the context-hygiene rules are spending.

ask-matt/SKILL.md:32. Avoid: context window, token limit.
Primary source (of a session)

The session as it happened, unsummarised. Every phase-boundary move except Continue converts it into a secondary source. Distinct from a primary source of knowledge, which is what this repository cites claims to.

PHASE-BOUNDARIES.md:44. Avoid: full context, raw history.
