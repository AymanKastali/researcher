Routing table

Situation to flow, in one page. Read top to bottom; the first row that matches wins.

Almost the whole decision reduces to one measurement, and it is not size, difficulty, or importance. Will this work outlive one context window? Establish that first and most rows below answer themselves.

The measurement

The floor

If the whole change fits in one context window, the spec and the tickets are both skipped. Go straight to /implement.

One thing this table cannot decide

The judgement that stays yours

Every row lands on something. Nothing in the set decides whether a change is worth the ceremony at all — the first row is this workspace's addition, not the set's.

A router can know what shape a change is. It cannot know what it is worth.
