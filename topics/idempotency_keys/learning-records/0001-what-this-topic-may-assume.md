# What this topic may assume the reader already knows

**Answer: nothing outside this topic.** Settled 2026-09-11 by a repo-wide rule —
each topic is independent and must not refer to any other. See
`docs/agents/topic-independence.md`.

## What this replaced

This record originally said the opposite. It was opened on 2026-09-11 to capture
that Ayman had finished another course in this repo first, and it drew three
conclusions from that: do not re-teach idempotence itself, treat the
single-transaction boundary as leverage rather than new material, and keep
Lesson 01 short because the genuinely new surface was narrow.

Two of those conclusions survive; the reason given for them does not. Lesson 01
is short because the key's algorithm is genuinely small, not because something
else covered the groundwork. Nothing may be skipped on the grounds that another
topic taught it.

## What still holds

- **The genuinely new material in this topic is narrow**: the key is supplied by
  the *client* rather than generated by the server; the server must return a
  *stored response body*, not merely skip the work; and there are duplicate
  cases a simple dedup table never has — a retry arriving while the original is
  still running, and a key reused with a different payload. That narrowness is
  the reason Lesson 01 can be short.
- **Whatever a lesson needs, the lesson teaches.** The dual-write problem,
  at-least-once delivery and the transactional outbox all appear in this topic.
  Each is explained where it is used, in one or two sentences, with no pointer
  anywhere else. See [[0005-deferred-work-is-a-transactional-outbox]].
- **The single-transaction argument is still the spine of Lesson 01**, stated in
  its general form: a marker is only trustworthy if it commits with the thing it
  marks.

## The cost of the change

Lesson 04's opening warm-up was a genuinely interleaved quiz — one question from
this topic, one from another — which is the strongest retrieval format available
when two mechanisms are confusable. That format is no longer possible within a
topic. Both questions now come from earlier lessons here, which is spacing
without interleaving: still useful, measurably less so.
