_run_once

One iteration of the loop, compressed for lookup: the six steps, the constants, the line numbers, and the round trip an await takes through them. Everything here is against CPython tag v3.13.11.

Line numbers are exact against Lib/asyncio/base_events.py at tag v3.13.11, and hold for that tag only. _run_once is byte-identical between v3.13.0 and v3.13.11.

The six steps

One iteration, in order. Only step 3 blocks; only step 6 runs anything.
# Step What happens Lines
1 Timer-heap hygiene Compaction if len(_scheduled) > 100 and cancelled/total > 0.5; otherwise pop cancelled handles off the head only. 1978–1999
2 Compute the poll timeout 0 if _ready or _stopping; else head._when - now clamped to [0, 86400]; else None. 2001–2010
3 The only blocking call event_list = self._selector.select(timeout) → epoll_wait(2) on Linux. 2012
4 Events → callbacks _process_events appends the stored reader/writer handles to _ready. No user code runs. 2013, and selector_events.py:740-752
5 Due timers → _ready Pop every TimerHandle with _when < now + _clock_resolution. 2017–2025
6 Drain ntodo = len(_ready), then ntodo × popleft() + _run(). The only place callbacks are called. 2027–2051

The four rules of the drain

  1. The batch is fixed before it starts. ntodo = len(self._ready) is read once. Callbacks scheduled by callbacks run next iteration, after another poll.
  2. No lock is taken. A concurrent call_soon_threadsafe append can only make the real length larger than ntodo, never smaller, and deque.append/popleft are individually atomic.
  3. A cancelled handle still consumes a slot. It is popped, skipped at base_events.py:2036-2037, and the counter has already budgeted for it.
  4. Debug mode is checked per handle, not per iteration — if self._debug: is inside the for at line 2038.

The three poll timeouts

The await round trip

await loop.sock_recv(s, n), stage by stage.
Stage Call Where
0 — fast path sock.recv(n) tried first. Success means no suspension at all. selector_events.py:374-377
1 — register create_future(), then _add_reader(fd, self._sock_recv, fut, sock, n) → selector.register(fd, EVENT_READ, (handle, None)) selector_events.py:378-384, 274-287
2 — suspend Future.__await__ sets the flag and yield self; the Task subscribes __wakeup and records _fut_waiter. futures.py:283-289, tasks.py:324-343
3 — readiness epoll_wait returns; step 4 appends; step 6 runs _sock_recv, which calls fut.set_result(data). selector_events.py:740, 390-404
4 — one extra iteration set_result → __schedule_callbacks → call_soon(__wakeup). The ntodo snapshot defers it to iteration N+1. futures.py:248-258, 158-170
5 — resume __wakeup → __step → coro.send(None); Future.__await__ returns self.result(). tasks.py:373-387, 281-304

The _asyncio_future_blocking signal

getattr(result, '_asyncio_future_blocking', None) in Task.__step_run_and_handle_result (tasks.py:323-369).
Value Meaning Response
None Not a Future. result is None → call_soon(__step); generator or anything else → RuntimeError.
False A Future, yielded rather than awaited. RuntimeError('yield was used instead of yield from …')
True A Future that suspended properly. Clear the flag, add_done_callback(__wakeup), set _fut_waiter, return.

Also check the loop — futures._get_loop(result) is not self._loop raises before any of the above — and self-await, which raises “Task cannot await on itself”.

The Task's three states

From the invariant comment at tasks.py:76-93.
State Condition Meaning cancel() does
1 _fut_waiter is not None and not _fut_waiter.done() Waiting on a pending Future. Cancels that Future.
2 _fut_waiter is None or done, and __step() is scheduled Waiting to be stepped. Sets _must_cancel.
3 _fut_waiter is None and __step() is not scheduled Currently executing. Sets _must_cancel.
